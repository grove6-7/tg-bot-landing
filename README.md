# Лендинг «Telegram-боты под ключ»

Небольшой статический сайт-визитка для приёма заявок.

## Настройка
1. В `index.html` замените `YOUR_TELEGRAM_USERNAME` на ваш username в Telegram (в двух ссылках и в футере).
2. При необходимости отредактируйте услуги, цены и текст брифа в `index.html`.

## Запуск локально
Откройте `index.html` в браузере или поднимите простой сервер:
```bash
python -m http.server 8000
```
Сайт будет доступен на http://localhost:8000
